# 漫工厂 AI v0.1 可运行 MVP

这是一个零依赖的本地 Web MVP，包含角色库、作品管理、8 格分镜、逐格画面生成与版本切换、编辑器和 PNG 长图导出。内置 mock AI 适配流程，不需要外部 API 密钥。

## 启动

需要 Node.js 20 或更新版本。在此文件夹运行：

```sh
node server.mjs
```

访问 `http://localhost:4173`。首次启动会在 `data/state.json` 创建本地数据文件；作品、角色与编辑内容会保存到这里，并在浏览器本地留有副本。设置 `PORT` 可更改端口。

## 演示流程

1. 打开预置作品《今天一定准时下班》，进入工作台。
2. 在左侧选择画格，在右侧编辑画面描述、动作、对白和旁白。
3. 切到“画面”并生成本格，可在不同版本间切换；任务通过本地任务 API 排队并返回 mock 结果。
4. 生成分镜、添加画格、调整比例和间距；内容自动保存。
5. 选择“导出长图”，下载 PNG。
6. 在“角色库”新增角色，在作品库复制、归档或删除作品。

## 本地 API

- `GET /api/v1/health`：健康状态
- `GET/PUT /api/v1/state`：读写本地工程状态
- `GET /api/v1/works`、`GET /api/v1/characters`：作品和角色列表
- `POST /api/v1/jobs`、`GET /api/v1/jobs/:id`、`POST /api/v1/jobs/:id/cancel`：mock 任务队列

服务只绑定 `127.0.0.1`，不包含用户登录、云端同步或外部模型调用。接入真实 AI、账号和生产数据库需按产品设计文档继续实现。清理 `data/state.json` 会删除服务器上的本地作品；浏览器数据仍可保留一份副本。
